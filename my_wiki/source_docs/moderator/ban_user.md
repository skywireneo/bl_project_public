# ⚖️ Процедура бана пользователя

Пошаговая инструкция по блокировке аккаунта пользователя.

## Шаг 1: Найдите пользователя

Откройте панель администратора и введите логин или email пользователя в поиск.

## Шаг 2: Перейдите в профиль

Кликните на имя пользователя, чтобы открыть его профиль.

![Интерфейс профиля пользователя](../../assets/images/123.png)

## Шаг 3: Заблокируйте аккаунт

1. Перейдите на вкладку **"Безопасность"**
2. Нажмите кнопку **"Заблокировать аккаунт"**
3. Выберите причину из списка:
   - Спам
   - Нарушение правил
   - По запросу пользователя
   - Другое

## Шаг 4: Укажите причину

В поле "Комментарий" обязательно укажите детали инцидента. Это важно для аудита.

## Шаг 5: Подтвердите действие

Нажмите **"Применить"**. Пользователь будет заблокирован немедленно.

!!! warning "Важно"
    После блокировки пользователь не сможет войти в систему. Убедитесь, что это правильное решение.
